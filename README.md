Amazon Sales Dashboard – Excel Data Analytics Project

Overview

This project is an interactive Amazon Sales Dashboard developed using Microsoft Excel to analyze sales data and present key business metrics through visualizations and interactive filters.

Dashboard KPIs

- Total Sales
- Total Quantity Sold
- Average Rating
- Total Unit Price

Dashboard Features

- Interactive category filter
- State-wise filter
- Product name filter
- Sales analysis by category
- Quantity sold analysis
- Average rating comparison
- Total unit price visualization

Tools & Technologies

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Data Visualization
- KPI Dashboard Design

Objective

The objective of this project is to transform raw sales data into an interactive dashboard that helps users explore sales performance across products, categories, and states.
